# Optional media plugins

These 14 sources are for manual installation and are never app resources.
`../bundles/Luna-Media.lunabundle` contains every `.js` file in this directory.
Regenerate it from the repo root with `python3 scripts/build_media_plugin_bundle.py`.
Import the bundle in Luna → Settings → Plugins → Import from Files, or open the
file in Luna. Review and accept each plugin's permissions. Individual `.js`
imports remain supported. See `claudedocs/plugins.md` for the format and limits.
