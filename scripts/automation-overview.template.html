Get Current Safari URL

A URL you can pass straight to the next Shortcut action. No inputs, no save, no app launch.

Safari page→Get Current Safari URL→Any URL action

Same source as Reader: the last page URL reported by the Luna Safari extension. The full query string and fragment are preserved.

Enable the extension for the website. This reads the last reported page, rather than querying Safari’s active tab live. It uses Reader’s existing 72-hour freshness window; missing, stale or non-web URLs produce an error. After installing a build containing this change, search for “Get Current Safari URL” under Luna Reader in Shortcuts.

How the pieces compose

Actions → values → actions

Entities are typed objects with properties available as Shortcuts magic variables. “Find” actions resolve current storage; result entities carry values between steps. Automatic shortcuts have a Siri/Spotlight entry; other discoverable intents can still be added manually.

Music controls also power widgets and Live Activities. Reader’s two raw download-job controls are private, and are labelled accordingly below. No separate Mac App Intent catalogue was found in this repository; Orbit is outside this inventory.

Changes → journal → your workflow

  1. Enable Change Notifications in the owning app, if you want alerts.
  2. Run that app’s Get Data Changes with your saved token.
  3. Filter Changes, resolve Item ID with a Find action, then process.
  4. Dismiss processed notifications. Save Next Token after success; repeat while Has More is true.

Each app retains 10,000 changes; pages hold up to 500. Notification delivery depends on system settings. The journal works with alerts off. Domain writes and journal writes are separate, so reconcile a full listing if exhaustive recovery matters.
