# Orbit extraction

Luna Code and the Code build/install services from Luna Mac now live in the standalone
[Orbit repository](https://github.com/diaruga777/Orbit). Orbit owns its iOS and Mac
clients, pairing, signing configuration, source editor, schedules and agent MCP.
Luna Mac continues to serve Vault and Music. Existing Luna data is preserved;
Orbit does not adopt Luna’s App Group, keychain identity or developer account.
See Orbit’s README for installation and setup.
